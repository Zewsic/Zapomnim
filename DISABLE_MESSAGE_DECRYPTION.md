# Флаг отключения расшифровки сообщений

## Описание

Добавлен флаг окружения `DISABLE_MESSAGE_DECRYPTION`, который полностью отключает все функции связанные с расшифровкой голосовых и видео сообщений.

## Использование

### Переменная окружения

```bash
# Отключить расшифровку (любое из значений)
DISABLE_MESSAGE_DECRYPTION=True
DISABLE_MESSAGE_DECRYPTION=true  
DISABLE_MESSAGE_DECRYPTION=1
DISABLE_MESSAGE_DECRYPTION=yes

# Включить расшифровку (по умолчанию)
DISABLE_MESSAGE_DECRYPTION=False
DISABLE_MESSAGE_DECRYPTION=false
DISABLE_MESSAGE_DECRYPTION=0
DISABLE_MESSAGE_DECRYPTION=no
# или не устанавливать переменную вообще
```

### В .env файле

```env
# Отключить все функции расшифровки голосовых и видео сообщений (по умолчанию False)
DISABLE_MESSAGE_DECRYPTION=False
```

## Что отключается

Когда флаг установлен в `True`, полностью отключаются:

1. **Обработка голосовых сообщений** - роутер `voice_transcribe_router` не подключается
2. **Обработка видео-сообщений** - функция `transcribe_voice_messages` возвращается сразу
3. **UI элементы настроек** - кнопка "Расшифровка голосовых сообщений" скрывается из меню
4. **Обработчик настроек** - callback для `transcribe_voice_messages_settings` показывает ошибку
5. **Статистика** - счетчик расшифрованных сообщений показывает 0
6. **Публичный роутер** - обработка голосовых/видео сообщений в публичном боте отключается

## Измененные файлы

- `config.py` - добавлен флаг `DISABLE_MESSAGE_DECRYPTION`
- `.env` - добавлена переменная окружения
- `main.py` - условное подключение роутера расшифровки
- `handlers/features/voice_messages_transcriber.py` - проверка флага в функциях
- `handlers/features/process_message.py` - проверка флага при обработке сообщений
- `handlers/settings.py` - блокировка доступа к настройкам расшифровки
- `keyboards/settings.py` - скрытие кнопки настроек расшифровки
- `handlers/data_management.py` - обнуление статистики расшифровки

## Безопасность

Флаг проверяется на уровне:
- Роутинга (роутер не подключается)
- Обработки сообщений (функции возвращаются сразу)
- UI (элементы скрываются)
- API (обработчики блокируются)

Это гарантирует что никакие функции расшифровки не будут работать при включенном флаге.
